# Práctica 1
En esta práctica entendimos conceptos básicos de electrónica, hicimos dos circuitos básicos y utilizamos el osciloscopio.

Para el primer circuito utilizamos una resistencia, un foco LED, unos jumpers, dos caimanes y una protoboard. Lo alimentamos con una fuente de alimentación.

Para el segundo circuito utilizamos tres resistencias, dos capacitores, un foco LED y un módulo 555.

Conectamos el segundo circuito al osciloscopio para observar cómo variaba la señal al parpadear el LED.

Al tener conectado un capacitor electrolítico, el foco parpadea de manera constante.

Al tener conectado el capacitor de cerámica, el foco parece que no parpadea, pero al observarlo con el osciloscopio podemos ver que parpadea tan rápido que no podemos percibirlo a simple vista.
