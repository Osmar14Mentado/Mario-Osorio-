# Práctica 1
En está práctica enntendimos conceptos básicos de la electrónica, hicimos dos cricuito básicos y utilizamos el osciloscopio.

Para el primer circuito utilizamos una resistencia, un foco led, unos jumpers, dos caimanes, una protoboard y la alimentamos  con una fuente de alimentación.

Para el segundo circuito utilizamos tres resistencias, dos capacitores, un foco led y un módulo 555.

Conectamos el segundo circuito al osciloscopio para ver como variaba al parpadear. 

Al tener  conectado un capacitor electrolítico el foco parpadea de manera constante. 

Al tener conectado el capacitor de cerámica el foco parece que no parpadea, pero al verlo con el osciloscopio podemos ver que parpadea tan rápido que no podemos percibirlo.
